# 金門機場每週航班統計

以互動圖表與航班清單，呈現 **2026 年 10 月 12 日至 10 月 18 日**金門機場的預定進場與離場班次。本專案使用 AI 協助討論規格與完成網頁，作為 Vibe Coding 互動網頁作業。

> 本網站依官方月班表整理預定班次，並非實際起降紀錄。資料內嵌於網頁，沒有串接即時 API，也不會自動抓取最新航班。

## 網站入口

[開啟金門機場每週航班統計](https://zekke15.github.io/kinmen-flights/)

此網址須先完成 GitHub Pages 設定與部署才能使用。若尚未發布，可下載 `index.html`，直接使用瀏覽器開啟。

## 設計目的

希望讓金門居民、旅客與對航空交通有興趣的使用者，快速了解一週的預定班機分布，並依日期、航空公司與航線查看明細。

## 主要功能

- **統計卡片**：顯示篩選範圍內的進場、離場與合計班次。
- **每日長條圖**：比較週一至週日的進出班次，點選日期即可篩選明細。
- **組合篩選**：依日期、航空公司、對端機場與進出方向查詢。
- **航班搜尋**：輸入完整或部分航班編號，例如 `B7-8921`。
- **航班明細**：顯示日期、航班編號、航空公司、方向、航線與班表狀態。
- **取消排除**：取消航班保留在明細，但不納入統計卡片與圖表。
- **CSV 匯出**：下載目前篩選結果，包含取消紀錄及其狀態。
- **重設篩選**：回到全週資料。
- **規格說明**：頁面底部提供可複製的作業規格與驗收項目。

## 操作方式

1. 開啟網站或本機的 `index.html`。
2. 查看全週統計卡片與每日圖表。
3. 選擇日期、航空公司、對端機場或方向，縮小查詢範圍。
4. 點選圖表中的日期，查看該日航班。
5. 在搜尋欄輸入航班編號，查找指定航班。
6. 按「匯出篩選結果 CSV」下載資料；按「重設篩選」恢復全週顯示。

日期篩選影響統計卡片與明細；圖表固定保留七天，套用其他篩選條件。重新整理頁面後，篩選條件會回到預設值。

## 資料來源與統計規則

資料來源：[金門航空站 115 年（2026 年）10 月份班機時刻表 PDF](https://www.kma.gov.tw/UploadFile/20260930112018.pdf)

資料整理日期：2026/10/19。統計期間固定為 2026/10/12–2026/10/18，以臺灣日期為準。

1. **進場**指抵達金門的班機；**離場**指從金門出發的班機。
2. 依每個航班的飛行星期展開日期，套用「僅飛」與「取消」等特殊日期備註。
3. 每個日期、方向、航班編號只計算一次；每次起飛或降落各算一架次。
4. 「某日為加班機」表示航班性質，不解讀為僅在該日期飛行；只有「僅飛」限制日期。
5. 時間與機型調整不改變班次數。本版明細未列出起降時間。
6. 10/15 的 `B7-8921`、`B7-8922` 列為取消，不納入統計。
7. 10/17 納入澎湖航線的 `B7-8995`、`B7-8996`。
8. 進出班次獨立計算。`B7-9206` 依原表每日、`B7-9208` 依原表週一四五日計入，不因對向班次不對稱而自行改表。

## 發布到 GitHub Pages

1. 確認 `index.html` 位於專案根目錄。
2. 在專案開啟 **Settings → Pages**。
3. 將 **Source** 設為 **Deploy from a branch**。
4. 選擇 **main** 分支及 **/(root)** 資料夾，按 **Save**。
5. 等待部署成功，使用 Pages 頁面顯示的網址開啟網站。

## AI 協助與調整過程

1. 討論金門機場每週進出航班統計的構想與使用情境。
2. 查找公開資料，確認取得的是官方月班表，尚未取得指定週完整的實際起降紀錄。
3. 將實作範圍調整為「載入官方班表資料並自動統計」。
4. 加入每日圖表、組合篩選、搜尋及 CSV 匯出。
5. 補上取消航班排除、進出獨立計算，以及資料來源與限制說明。

## 使用限制

- 不提供即時航班、延誤、實際抵達或起飛狀態。
- 未涵蓋月班表以外的臨時增班、臨時取消、軍機與所有非定期航班。
- 不提供訂票功能，不能作為當日搭機依據。
- 若官方班表有誤或後續調整，須重新核對並修改內嵌資料。
- 即時 API 串接屬未來擴充方向，目前尚未實作。
